# GameKeeper

[English](../README.md) | [简体中文](README-CN.md) | [開發文件](develop.md)

GameKeeper 是一個輕量級 Windows 遊戲輔助工具，可讓指定遊戲或應用程式在背景執行時，仍表現得像目前位於前景。它也能擷取目標遊戲視窗，顯示在獨立且可縮放的 CaptureWindow 中。

## 功能

- **前景與焦點偽造**：讓會因背景化而暫停的遊戲或應用程式維持執行。
- **可縮放擷取畫面**：擷取目標視窗畫面，並即時縮放到符合 GameKeeper 擷取視窗大小。
- **輸入轉送**：轉送滑鼠移動、hover/leave、左鍵、右鍵、中鍵，以及鍵盤 down/up 事件到目標視窗。
- **子控制項定位**：滑鼠事件會盡量送到游標所在位置的 child window/control。
- **擷取 title bar 控制**：CaptureWindow 本身不顯示原生 title bar，可使用擷取畫面中的 title bar 區域移動、最小化、最大化、還原或關閉擷取視窗。
- **程序清單圖示**：程序清單會顯示應用程式圖示與 PID，方便辨識目標。
- **x86/x64 支援**：依照目標程序架構載入對應的輔助檔案。

## 使用方式

1. 執行 `GameKeeper.exe`。
2. 點擊 **Refresh** 更新程序清單。
3. 選擇目標程序後點擊 **Attach**。
4. 在已附加程序清單中點擊 **Capture** 開啟擷取視窗。
5. 依需求調整擷取視窗大小，遊戲畫面會跟著縮放。
6. 透過擷取視窗操作遊戲或應用程式。
7. 使用完成後點擊 **Detach**，或直接關閉 GameKeeper 以 detach 所有已附加程序。

## 注意事項

- 若目標遊戲或應用程式以系統管理員權限執行，GameKeeper 也需要以系統管理員權限執行。
- 部分遊戲使用 DirectInput、Raw Input 或 `GetAsyncKeyState` 等輪詢方式取得輸入，標準視窗訊息轉送不一定能觸發所有輸入路徑。
- 請僅用於合法的個人、教育或研究用途，不要用於違反遊戲服務條款或反作弊規範的情境。
