# GameKeeper

[English](../README.md) | [繁體中文](README-ZH.md) | [开发文档](develop.md)

GameKeeper 是一个轻量级 Windows 游戏辅助工具，可让指定游戏或应用程序在后台运行时，仍表现得像当前位于前台。它也能捕获目标游戏窗口，显示在独立且可缩放的 CaptureWindow 中。

## 功能

- **前台与焦点伪造**：让会因后台化而暂停的游戏或应用程序继续运行。
- **可缩放捕获画面**：捕获目标窗口画面，并实时缩放到符合 GameKeeper 捕获窗口大小。
- **输入转发**：转发鼠标移动、hover/leave、左键、右键、中键，以及键盘 down/up 事件到目标窗口。
- **子控件定位**：鼠标事件会尽量发送到光标所在位置的 child window/control。
- **捕获 title bar 控制**：CaptureWindow 本身不显示原生 title bar，可使用捕获画面中的 title bar 区域移动、最小化、最大化、还原或关闭捕获窗口。
- **进程列表图标**：进程列表会显示应用程序图标与 PID，方便识别目标。
- **x86/x64 支持**：根据目标进程架构加载对应的辅助文件。

## 使用方式

1. 运行 `GameKeeper.exe`。
2. 点击 **Refresh** 更新进程列表。
3. 选择目标进程后点击 **Attach**。
4. 在已附加进程列表中点击 **Capture** 打开捕获窗口。
5. 按需求调整捕获窗口大小，游戏画面会跟随缩放。
6. 通过捕获窗口操作游戏或应用程序。
7. 使用完成后点击 **Detach**，或直接关闭 GameKeeper 以 detach 所有已附加进程。

## 注意事项

- 如果目标游戏或应用程序以管理员权限运行，GameKeeper 也需要以管理员权限运行。
- 部分游戏使用 DirectInput、Raw Input 或 `GetAsyncKeyState` 等轮询方式获取输入，标准窗口消息转发不一定能触发所有输入路径。
- 请仅用于合法的个人、教育或研究用途，不要用于违反游戏服务条款或反作弊规范的场景。
